## Deliverables

1. Populate `src-tauri/Cargo.toml` with all required dependencies at the versions specified in the design document:

   **Core**:
   - `tauri = "2"` (with `features = ["protocol-asset"]`)
   - `serde = { version = "1", features = ["derive"] }`
   - `serde_json = "1"`
   - `tokio = { version = "1", features = ["full"] }`
   - `thiserror = "2"`
   - `anyhow = "1"`

   **Cryptography**:
   - `chacha20poly1305 = "0.10"`
   - `argon2 = "0.5"`
   - `hkdf = "0.12"`
   - `sha2 = "0.10"`
   - `blake3 = "1"`
   - `rand = "0.9"` (must be >= 0.9 for edition 2024 `gen` keyword)
   - `zeroize = { version = "1", features = ["derive"] }`
   - `secrecy = "0.10"`
   - `x25519-dalek = "2"`

   **Storage**:
   - `rusqlite = { version = "0.34", features = ["bundled-sqlcipher-vendored-openssl"] }`
   - `uuid = { version = "1", features = ["v4", "serde"] }`

   **Dev-dependencies**:
   - `proptest = "1"`
   - `tempfile = "3"`
   - `assert_matches = "1"`

2. Create the five module directories under `src-tauri/src/` with minimal placeholder files:

   For each module (`crypto`, `auth`, `storage`, `memory`, `ui`):
   - `mod.rs` — module doc comment + `pub mod error;` + `pub mod types;`
   - `error.rs` — empty `thiserror` enum with module doc comment
   - `types/mod.rs` — empty file with module doc comment

3. Declare all five modules in `src-tauri/src/lib.rs`:
   ```rust
   pub mod auth;
   pub mod crypto;
   pub mod memory;
   pub mod storage;
   pub mod ui;
   ```

4. Verify `cargo clippy --all-targets --all-features -- -D warnings` produces zero warnings
5. Verify `cargo fmt --all -- --check` passes
6. Verify `cargo test --all-targets` compiles and passes (no tests yet, but compilation must succeed)

## Validation Checkpoint

**Automated**:
```bash
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets
```
All three must pass.

**Manual verification**:
- Confirm all 15 placeholder files exist (5 modules × 3 files: `mod.rs`, `error.rs`, `types/mod.rs`)
- Open `src-tauri/src/lib.rs` — confirm all five module declarations are present
- `cargo tree` — verify no duplicate versions of security-critical crates (`rand`, `zeroize`, `chacha20poly1305`)

**Acceptance criteria**:
- Zero clippy warnings
- `cargo fmt` reports no diffs
- All five modules compile and are reachable via `src-tauri/src/lib.rs`
- `rand` resolves to `>= 0.9`

## Implementation Notes

- Placeholder `mod.rs` pattern for each module (example for `crypto`):
  ```rust
  //! Cryptographic primitives for Arx Runa.
  //!
  //! Provides key derivation, chunk encryption/decryption, file key management,
  //! and BLAKE3 checksums. Implemented in Phase 1.

  pub mod error;
  pub mod types;
  ```

- Placeholder `error.rs` pattern:
  ```rust
  //! Error types for the crypto module.

  use thiserror::Error;

  /// Errors produced by the crypto module.
  #[derive(Debug, Error)]
  pub enum CryptoError {
      // Variants added in Phase 1.
  }
  ```

- Placeholder `types/mod.rs` pattern:
  ```rust
  //! Domain types for the crypto module.
  //!
  //! Newtypes (FileKey, ChunkIndex, etc.) are added in Phase 1.
  ```

- The `#[derive(Debug, Error)]` on an empty enum will produce a clippy warning about a `#[non_exhaustive]` recommendation. Suppress with `#[allow(dead_code)]` on the enum or add `#[non_exhaustive]` — choose one approach consistently across all five modules.
- `rusqlite` with `bundled-sqlcipher-vendored-openssl` compiles OpenSSL from source — first `cargo build` after adding this dep will take several minutes. This is expected.
- `x25519-dalek` requires the `getrandom` crate's `js` feature when targeting WASM. Since `x25519-dalek` is backend-only (`src-tauri/`), this is not an issue for the Tauri backend target. Do not add `getrandom` with `js` feature unless the frontend also uses it.
