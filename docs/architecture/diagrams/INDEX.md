# Diagram Index

Mermaid diagrams for VoidGate architecture and flows. Generated by `/diagram`. Regenerate any diagram with `/diagram update <filename>`.

## Organization

**Design-specific diagrams** are co-located with their design documents:
- See `docs/architecture/designs/<design-name>/diagrams/` for diagrams specific to that design
- Examples: Authentication Flow, Chunk Pipeline, Cloud Sync Sequence, etc.

**Cross-cutting diagrams** (below) remain in this central directory:
- SSOT Information Flow — spans multiple modules
- End-to-End Encryption Flow — spans auth, crypto, storage
