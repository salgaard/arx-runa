# Phase 6.2: Frontend State Contexts and Tauri Invoke Wrapper

**Parent roadmap**: [roadmap.md](roadmap.md)  
**Design sections**: State Contexts (lines 559-691), Tauri IPC Integration (lines 853-897) of [design.md](../design.md)  
**Depends on**: [Phase 6.1](6.1-ipc-core-and-error-sanitisation.md) (IPC response types required for frontend deserialisation)

## Deliverables

1. `invoke_command<A, R>(cmd: &str, args: A) -> Result<R, IpcError>` generic async function in `src/lib.rs`, wrapping `window.__TAURI__.core.invoke` via `wasm_bindgen` and deserialising the result with `serde_wasm_bindgen`
2. Frontend `IpcError` struct in `src/lib.rs` with `kind: String` and `message: String` fields, deserialised from the `{"kind": "...", "message": "..."}` JSON shape produced by the backend
3. `SessionProvider` component in `src/auth/session_provider.rs`: polls `get_session_status` every 5 seconds via `spawn_local` + `gloo_timers`, registers a stop signal on `on_cleanup` to prevent stale intervals after unmount
4. `SessionState` signal fields: `is_unlocked: bool`, `vault_id: Option<String>`, `timeout_seconds: u64`, `authenticating: bool`, `error: Option<String>`
5. `use_session()` accessor hook and `use_session_actions()` hook, both backed by `provide_context` / `use_context`, panicking with a clear message if called outside a `SessionProvider`
6. `VaultState` signal in `src/vault/vault_state.rs` with fields: `current_path: String`, `files: Vec<FileEntry>`, `loading: bool`, `error: Option<String>`, `selected: Vec<String>`
7. `VaultActions` struct with `navigate(path: String)` (calls `list_directory` IPC and updates `files` and `current_path`) and `clear()` (wipes all `VaultState` fields to defaults — used on lock)
8. `SyncContext` in `src/sync/sync_context.rs` with `SyncStatus` signal tracking current sync state (idle, running, conflict, error)
9. Unit tests: `VaultActions::clear()` resets all fields to defaults; `SessionState` transitions from `authenticating: true` to `is_unlocked: true` on success, and to `error: Some(...)` on failure

## Implementation Notes

- `invoke_command` uses `serde_wasm_bindgen::from_value` for deserialisation; errors from Tauri IPC arrive as a serialised `IpcError` JSON object on the rejected promise, which must be deserialised separately from success responses
- `gloo_timers::future::TimeoutFuture` is the preferred timer for polling inside `spawn_local`; the stop signal should be a `Rc<Cell<bool>>` that the cleanup closure sets to `true`
- `use_context::<SessionState>()` returns `Option<...>` in Leptos; the `use_session()` hook should `.expect("SessionProvider not found in component tree")` to give a clear error message during development
- `FileEntry` on the frontend mirrors the backend `types.rs` definition; keep the two in sync manually until a shared type generation step is introduced
- `withGlobalTauri: true` must be set in `tauri.conf.json` before this phase will function — confirm this is present (it is set in Phase 6.4, but the build-time requirement starts here; set it now)
