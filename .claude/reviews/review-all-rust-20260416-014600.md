## Detailed Findings and Recommended Fixes

### Non-atomic credential rotation — CF-001

- **Severity**: HIGH
- **Occurrences**: 2 (out of 3 cycles)
- **Cycles Seen**: cycle-1
- **Reviewers**: rust-reviewer, security-reviewer
- **Category**: CORRECTNESS
- **Confidence**: MEDIUM
- **Disposition**: ACTIONABLE_NOW
- **Location**: `src-tauri/src/auth/ceremonies/change_password.rs`, `src-tauri/src/auth/ceremonies/rotate_key_file.rs`
- **Rule Refs**: R-129, R-133, R-141
- **Design Refs**: D-006, D-007, D-034
- **Problem**: Rotation commits local rekey before cloud header upload confirmation.
- **Evidence**: Both ceremony paths commit/rekey before upload and return on upload failure without rollback.
- **Plan Context**: Phase 2.4 ceremonies; retry hardening deferred later.
- **Recommended Fix**: Introduce durable pending-rotation reconciliation protocol.
- **Proposed Solution**: Persist pending header, reconcile at startup, and guard sensitive operations while pending exists.
- **Blast Radius**: CROSS-MODULE
- **Estimated Complexity**: HIGH
- **Risk if Unchanged**: Local/cloud divergence and lockout risk.

### Auth-storage boundary leak in ceremonies — CF-002

- **Severity**: HIGH
- **Occurrences**: 1
- **Cycles Seen**: cycle-1
- **Reviewers**: architecture-reviewer
- **Category**: BOUNDARY_LEAK
- **Confidence**: MEDIUM
- **Disposition**: ACTIONABLE_NOW
- **Location**: `src-tauri/src/auth/ceremonies/*`
- **Rule Refs**: R-129, R-133
- **Design Refs**: D-013, D-023
- **Problem**: Auth ceremonies directly execute SQLCipher/storage responsibilities.
- **Evidence**: Schema init, SQL mutation, and rekey logic are owned in auth ceremony helpers.
- **Plan Context**: Current Phase 2.4 implementation.
- **Recommended Fix**: Move persistence into storage-owned boundary.
- **Proposed Solution**: Add storage port (e.g., `VaultPersistence`) and route ceremonies through it.
- **Blast Radius**: CROSS-MODULE
- **Estimated Complexity**: HIGH
- **Risk if Unchanged**: Higher regression risk and weak module boundaries.

- **Category**: ABSTRACTION_DEBT
