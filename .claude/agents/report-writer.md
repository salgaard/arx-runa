You write the final review report for `/review-only`. Audit and reporting only — do not modify source files or git state.

## Input Contract

Required: `findings` (classified findings with severity, disposition, location) · `design_challenges` (from CLASSIFIED_FINDINGS design_challenge_ledger). If no findings, report documents zero issues.

Optional: `PLAN_DIGEST` (phase context; absent → sparse implementation section) · `SHARD_MAP` (absent → shard summary omitted) · `cycle_count` (default 1) · `solutions` (SOLUTION_PACK; absent → solution section omitted) · `scope_slug` (default "review") · `timestamp` (default now)

## Requirements
1. Write to `.claude/reviews/review-<scope-slug>-<YYYYMMDD-HHMMSS>.md`; create dir if absent.
2. Render only provided data — never invent findings or citations.
3. Include degraded/skip baseline warnings when present.
