**Parent roadmap**: [roadmap.md](roadmap.md)

## Deliverables

1. `RcloneTransport` struct implementing `CloudTransport` in `src-tauri/src/storage/cloud/rclone.rs`
2. Rclone bundled as Tauri sidecar binary in `tauri.conf.json` `externalBin` field (platform-specific paths for Windows and Linux)
3. `run_rclone` function: construct subprocess via `tokio::process::Command`, pass args as `Vec<OsString>`, capture stdout/stderr, apply timeout via `tokio::time::timeout`
4. Remote path sanitisation — use the [Remote path sanitisation](../design.md#remote-path-sanitisation) rules from `design.md` (regex allowlist, reject `..`, reject leading `/`). Do not reproduce the regex here.
5. Stderr sanitisation — use the [Stderr sanitisation](../design.md#stderr-sanitisation) keyword list from `design.md`. Do not reproduce the list here.
6. Exit code mapping — use the [Exit code mapping](../design.md#exit-code-mapping) table from `design.md`. Do not reproduce values here.
7. `SyncConfig` struct with `max_concurrent` and `operation_timeout_seconds` — use the [Concurrency configuration](../design.md#concurrency-configuration) defaults from `design.md`. Do not reproduce values here.
8. Guided setup wizard functions:
   - `setup_s3_provider`: call `rclone config create` with access key ID, secret, bucket, region, endpoint
   - `setup_google_drive`: call `rclone config create` with OAuth flow, open browser via `tauri::api::shell::open`
9. Store `CloudEndpoint` in the Arx Runa app data directory — use the [Connection Descriptor](../design.md#connection-descriptor) paths from `design.md`. Do not reproduce platform paths here.
10. Use isolated `rclone.conf` in Arx Runa app data directory (`--config` flag on every invocation)
11. Integration tests with local Rclone filesystem remote

## Validation Checkpoint

**Automated tests**:
```bash
cargo test storage::cloud::rclone
```
Must pass with integration tests using local filesystem remote.

**Manual verification**:
- Run setup wizard for S3-compatible provider (MinIO or Backblaze)
- Verify `cloud-config.json` created with correct endpoint
- Verify `rclone.conf` created in Arx Runa app data directory
- Upload a test blob via `RcloneTransport`
- Verify blob appears in cloud bucket with correct UUID name

**Security check**: 
- Subprocess invocation does not use shell interpolation; args are passed as separate OS strings
- Path traversal attempts (`../escape.txt`) are rejected
- Credentials never appear in logs or error messages (stderr sanitisation works)

**Acceptance criteria**:
- `RcloneTransport` successfully uploads/downloads/deletes blobs to real cloud provider
- Path sanitisation blocks traversal attacks
- Credentials never appear in logs or error messages

## Implementation Notes

- Rclone binary must be downloaded from rclone.org and placed in `src-tauri/bin/` (platform-specific subdirectories)
- `tauri.conf.json` sidecar paths use `$RESOURCE` macro for portable builds
- On timeout, kill the Rclone process — see [Operation timeouts](../design.md#operation-timeouts) in `design.md` for the platform-specific kill mechanism
- OAuth flow requires `tauri::api::shell::open` to launch browser — test this manually (cannot be automated)
- `cloud-config.json` should be readable without authentication (needed for new-device recovery step 1)
